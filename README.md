# Kelowna Hindu Priest — ceremony booking site

Single-page site for [@kelownahindupriest](https://www.instagram.com/kelownahindupriest/): Vedic puja, havan & yagna, griha pravesh, navagraha shanti, rudra abhishek, vahan puja and astrology across the Okanagan.

Booking requests go straight to Pandit Ji's WhatsApp (+1 604 729 9408) via a three-step widget — no backend needed, so it runs free on GitHub Pages.

Built as a demo by [goodmarketer.ca](https://goodmarketer.ca).
